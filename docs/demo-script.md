
# SkillBridge Demo Script

**Target duration:** 5–8 minutes.

## 1. Introduction — 45 seconds

"SkillBridge is a collaboration platform that connects developers, designers and people with project ideas.

We noticed that many people want practical experience but struggle to find collaborators. Project owners also need an easier way to find people with the skills their projects require.

SkillBridge brings these people together."

## 2. Show the platform — 45 seconds

- Open the landing page.
- Explain the main purpose.
- Open Explore Projects.
- Show project cards and search/filter controls.

## 3. Demonstrate a user profile — 1 minute

- Log in with a prepared demo account.
- Open the profile.
- Show professional information, skills, interests and links.
- Show the profile image when Cloudinary is configured.

## 4. Demonstrate project creation — 1 minute

- Open Create Project.
- Enter a project title and description.
- Add technologies.
- Add roles and required slots.
- Set the maximum team size.
- Create the project.

Explain that role capacity helps project owners communicate exactly which collaborators they need.

## 5. Demonstrate collaboration — 1–2 minutes

- Open a second demo account.
- Browse the project.
- Select an available role.
- Submit a join request.
- Return to the owner account.
- Open the owner dashboard.
- Approve the request.
- Show updated membership and role capacity.

## 6. Demonstrate project management — 1 minute

- Edit the project.
- Show role requirements.
- Show the team member list.
- Demonstrate member removal using a prepared test member.
- Explain how capacity is updated.

## 7. Settings and themes — 30 seconds

- Open Settings.
- Demonstrate the theme preference.
- Show profile and account controls.

## 8. Conclusion — 30 seconds

"SkillBridge makes it easier for people to turn ideas into collaborative projects. It gives project owners a structured way to find contributors and gives developers and designers opportunities to gain practical experience."

## Demo preparation

- Use fictional demo accounts.
- Prepare one owner and one applicant account.
- Create a project with at least two roles.
- Prepare an available role for the application.
- Ensure the database and API are reachable.
- Configure Cloudinary if demonstrating image uploads.
- Verify the deployed frontend and backend before presenting.

## Fallback plan

If the live API or database becomes unavailable:

- Explain the intended workflow using prepared screenshots.
- Do not claim that an operation succeeded if it did not.
- Avoid exposing credentials, database URLs or server logs.
- Continue with the product explanation and feature walkthrough.
